### The important part: AI alone can't reliably measure dimensions

This is the one thing I'd be careful about in the PoC.

A normal phone photo doesn't inherently tell the AI that something is **50 mm** long. The AI can recognize the object and estimate relative dimensions, but you need some sort of **scale/reference** to get real measurements.

For example:

**Option A: Reference object**

* Put a known-size object next to the item.
* Example: a reference marker that's exactly 25 mm wide.
* AI/computer vision can use that to estimate the item's dimensions.

**Option B: AR measurement**

* Use the phone's AR capabilities to measure the object.
* This could potentially give you more useful real-world dimensions.

**Option C: 3D scanning**

* Use something like RealityScan to create a 3D representation.
* More complicated, but potentially much better for irregular objects.

For your **first PoC, I'd use Option A**. It's much easier to get working and demonstrate.

### AI's job

The AI should receive the image and return structured information rather than just a paragraph.

Something like:

```json
{
  "title": "M10 Hex Head Bolt",
  "category": "Fastener",
  "length_mm": 50,
  "diameter_mm": 10,
  "material": "Unknown",
  "confidence": 0.87
}
```

Your website can then take that information and display it in the inventory form.

### For the first version, I'd build only 4 things

**1. Camera**

* "Scan Item" button
* Capture image from phone

**2. AI analysis**

* Send image to a vision-capable AI model
* Get back item name/category/attributes

**3. Dimensions**

* Use a reference marker or measurement method
* Return basic L × W × H

**4. Inventory entry**

* Show the AI's results
* Let the user correct them
* Click **Add to Inventory**
